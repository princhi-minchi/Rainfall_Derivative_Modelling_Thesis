# Rainfall Derivative Modelling

Quantitative modelling and pricing of a rainfall-index derivative for agricultural drought risk in India.

This repository contains the research, data-processing pipeline and Python models developed for my MSc Finance thesis. The project explores whether a rainfall derivative can be designed to hedge agricultural yield losses caused by adverse rainfall, using Kanker district in Chhattisgarh, India as the case study.

Rather than starting with an existing financial index, I built the underlying rainfall index from raw geospatial weather data, modelled its relationship with agricultural yield, specified a derivative payoff, and compared alternative approaches for pricing the contract.

## What I Built

The project involved four main steps:

1. **Constructing the underlying rainfall dataset**

   * Processed daily gridded rainfall data stored in NetCDF files.
   * Used GADM administrative boundary data to isolate Kanker district.
   * Spatially clipped the rainfall grids and calculated district-level daily rainfall.
   * Created a multi-year daily rainfall time series for subsequent modelling.

2. **Designing a rainfall index**

   * Identified the rainfall window relevant to agricultural drought risk.
   * Analysed the distribution of daily rainfall and differentiated meaningful rainfall from trace precipitation.
   * Aggregated rainfall observations into an annual index that could serve as the underlying variable of the derivative.

3. **Linking rainfall to agricultural losses**

   * Combined the rainfall index with detrended historical crop-yield data.
   * Estimated a nonlinear yield-response function:

   $$
   Yield = \beta_0 + \beta_1 Rainfall + \beta_2 Rainfall^2
   $$

   * The fitted quadratic relationship achieved an \(R^2\) of approximately **0.75** in the sample used.

4. **Pricing the derivative**

   * Designed a drought-protection payoff analogous to a put option: payouts increase when the rainfall index falls below a predefined strike.
   * Implemented and compared multiple approaches to estimating the expected payoff and premium, including:

     * **Historical Burn Analysis (HBA)**
     * **Generalized Linear Model (GLM) simulation**
     * **Hidden Markov Model (HMM) simulation**
     * Experimental **SARIMA** time-series modelling
   * Monte Carlo implementations use simulated rainfall paths to generate distributions of derivative payouts rather than relying only on historical observations.

## Why Rainfall Derivatives?

Traditional agricultural insurance requires verification of individual losses and can suffer from high administrative costs, information asymmetry and slow claims processes.

A weather-index derivative instead pays according to an independently observable variable—in this case rainfall.

For example, a simplified drought contract can be represented as:

$$
Payoff = V \times \max(K-R,0)
$$

where:

* \(R\) = observed rainfall index
* \(K\) = drought strike
* \(V\) = monetary value paid per millimetre of rainfall deficit

The contract can therefore provide protection against severe rainfall shortages without requiring the holder to demonstrate the exact loss suffered.

The central challenge is then to construct an index that meaningfully represents the underlying agricultural risk and to estimate the distribution of that index well enough to price the contract.

## Modelling Approaches

### Historical Burn Analysis

The simplest benchmark estimates the expected derivative payout directly from historical rainfall observations.

Historical index values are passed through the derivative payoff function and the average historical payout is discounted to obtain an actuarial premium.

This provides a transparent benchmark but assumes that the historical sample adequately represents the future distribution of rainfall.

### Generalized Linear Model

A parametric rainfall model is fitted to the historical data and used to generate synthetic rainfall observations.

Thousands of simulated outcomes are then passed through the derivative payoff function, producing a Monte Carlo estimate of the expected payout.

This allows scenarios beyond the relatively limited set of historical annual observations to be incorporated into pricing.

### Hidden Markov Model

Rainfall is inherently regime-dependent: a rainy period and a dry period are not simply independent observations from the same distribution.

I therefore also experimented with a Hidden Markov Model in which rainfall behaviour can transition between latent weather regimes.

Synthetic rainfall sequences generated by the fitted HMM are converted into index values and derivative payouts, providing an alternative estimate of the contract premium.

### SARIMA

The repository also contains an experimental seasonal ARIMA implementation investigating whether rainfall dynamics can be represented directly as a seasonal time series.

## What I Learned

The project required combining several areas that are usually treated separately: derivatives pricing, agricultural economics, geospatial data processing, statistical modelling and time-series analysis.

The most interesting part of the project was that the financial modelling was only one part of the problem. Before a derivative could be priced, I first had to construct a defensible underlying variable from raw weather observations and determine whether it actually represented the economic risk the derivative was intended to hedge.

That process—from raw real-world data to index construction to payoff design and pricing—is the main focus of this repository.
